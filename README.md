## 🔄 Project Workflow

### 1. Data Loading

* Imported the raw dataset into Python using Pandas.
* Checked the number of rows and columns.
* Reviewed column names and data types.

### 2. Exploratory Data Analysis (EDA)

Performed EDA to understand the dataset and identify patterns.

Key activities:

* Descriptive statistics
* Missing value analysis
* Duplicate record detection
* Distribution analysis
* Trend and category analysis
* Identifying outliers

### 3. Data Cleaning

The dataset was prepared for further analysis by:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Standardizing column values
* Handling inconsistent or invalid records
* Creating required calculated columns

### 4. SQL Analysis

The cleaned data was loaded into **MySQL / SQL Server**.

SQL queries were used to answer important business questions such as:

* What is the total revenue?
* Which products/categories generate the highest sales?
* Who are the top customers?
* What are the monthly sales trends?
* Which regions perform best?
* What are the highest and lowest-performing segments?

### 5. Power BI Dashboard

The processed data was connected to Power BI to create an interactive dashboard.

The dashboard includes:

* KPI cards
* Sales / Revenue analysis
* Category-wise performance
* Customer analysis
* Regional analysis
* Monthly trends
* Interactive filters and slicers

### 6. Report Creation

A detailed analytical report was prepared covering:

* Business problem
* Data preparation
* Analysis methodology
* Key findings
* Business insights
* Recommendations

### 7. PPT Presentation

A professional presentation was created using **Gamma** to communicate the project:

* Problem statement
* Dataset overview
* Methodology
* Key analysis
* Dashboard insights
* Business recommendations
* Conclusion

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/yourusername/data-analytics-project.git
cd data-analytics-project
```

### Step 2: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 3: Run Python Analysis

Open the Jupyter Notebook:

```bash
jupyter notebook
```

Run the notebook to perform:

* Data loading
* EDA
* Data cleaning
* Data preparation

### Step 4: Run SQL Queries

1. Open MySQL / SQL Server.
2. Create the required database and tables.
3. Import the cleaned dataset.
4. Execute the SQL queries from:

```text
sql/analysis_queries.sql
```

### Step 5: Open Power BI

Open:

```text
powerbi/dashboard.pbix
```

Refresh the data and interact with the dashboard.
